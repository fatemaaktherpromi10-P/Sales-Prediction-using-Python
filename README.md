# Sales-Prediction-using-Python
Sales Prediction using Python. Predicts future product sales based on advertising expenditures (TV, Radio, Newspaper) using Linear Regression &amp; Random Forest models with actionable insights.

## Project Overview
The primary objective of this project is to analyze the impact of advertising budgets (TV, Radio, and Newspaper) on product sales and build predictive models to forecast future sales outcomes accurately[cite: 1].

### Key Tasks Performed:
* **Data Preparation:** Cleaned and preprocessed the dataset, handling missing values and ensuring data integrity[cite: 1].
* **Exploratory Data Analysis (EDA):** Visualized relationships between advertising mediums and sales using correlation heatmaps and pair plots.
* **Feature Selection & Splitting:** Selected optimal features and split the data into training and testing sets[cite: 1].
* **Model Training & Evaluation:** Implemented machine learning models like **Linear Regression** and **Random Forest Regressor** to predict sales[cite: 1].
* **Business Insights:** Derived actionable insights to help optimize marketing strategies and budget allocation[cite: 1].

## 📂 Dataset
The dataset typically includes the following columns:
* `TV`: Advertising budget spent on TV ad campaigns
* `Radio`: Advertising budget spent on radio ad campaigns
* `Newspaper`: Advertising budget spent on newspaper ads
* `Sales`: Resultant product sales
